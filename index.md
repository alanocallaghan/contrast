`contrast` contains a set of functions that can make 1 degree of freedom
contrasts for several type sof models. The package extends the
[`contrast()`](https://rdrr.io/pkg/rms/man/contrast.html) function from
the `rms` package.

To install it, use:

``` r

install.packages("contrast")

## For the devel version:
require(devtools)
install_github("Alanocallaghan/contrast")
```
